# 🚀 AstroMed — Astronaut Health Monitoring System

Навчальний програмний прототип системи моніторингу фізіологічних показників екіпажу під час космічної місії.

---

## ✨ Можливості

* **Симуляція біометрії:** генерація та відстеження показників для трьох умовних членів екіпажу.
* **Комплексний аналіз:** контроль пульсу, артеріального тиску, температури, $\text{SpO}_2$ та частоти дихання.
* **Оцінка ризиків:** розрахунок демонстраційного бала ризику та класифікація стану («Норма», «Увага», «Критичний»).
* **Візуалізація:** інтерактивні графіки динаміки показників і розподілу рівнів ризику на базі Dash.
* **Оптимізація ресурсів:** демонстраційний алгоритм розподілу обмежених медичних комплектів.

⚙️ Встановлення та запуск

Для швидкого запуск проєкту виконайте такі кроки:

    Завантажте проєкт у форматі ZIP та розархівуйте його в зручну для вас папку.

    Відкрийте командний рядок (cmd) безпосередньо у цій папці (найпростіший спосіб: відкрийте папку проєкту в Провіднику, клікніть на адресний рядок зверху, введіть cmd та натисніть Enter).

    Послідовно виконайте команди для встановлення необхідних бібліотек та запуску програми:
        1)py -m pip install plotly
        2)py -m pip install -r requirements.txt
        3)py main.py

    Після успішного запуску відкрийте браузер і перейдіть за адресою:
        [http://127.0.0.1:8050](http://127.0.0.1:8050)

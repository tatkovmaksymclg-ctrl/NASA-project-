# AstroMed — Astronaut Health Monitoring System

Навчальний програмний прототип системи моніторингу фізіологічних показників екіпажу під час космічної місії.

## Можливості

- симуляція біометричних вимірювань трьох умовних членів екіпажу;
- аналіз пульсу, артеріального тиску, температури, SpO₂ та частоти дихання;
- розрахунок демонстраційного бала ризику;
- класифікація стану: «Норма», «Увага», «Критичний»;
- графіки динаміки показників і розподілу рівнів ризику;
- демонстраційний алгоритм розподілу обмежених медичних комплектів;
- інтерактивна вебпанель на Dash.

## Встановлення

Потрібен Python 3.10 або новіший.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Встановлення залежностей:

```bash
pip install -r requirements.txt
```

python main.py

## Математична модель

Для кожного вимірювання обчислюється сумарний бал:

\[
R = w_1 H + w_2 O + w_3 T + w_4 P + w_5 B,
\]

де:

- \(H\) — бал відхилення частоти серцевих скорочень;
- \(O\) — бал відхилення SpO₂;
- \(T\) — бал відхилення температури;
- \(P\) — бал відхилення артеріального тиску;
- \(B\) — бал відхилення частоти дихання;
- \(w_i\) — вагові коефіцієнти, закладені в правилах моделі.

У поточній реалізації внески додаються безпосередньо: 0 балів — відхилень не виявлено, 1–4 — «Увага», 5 і більше — «Критичний».

## Модель розподілу ресурсів

Нехай \(r_i\) — бал ризику космонавта \(i\), а \(x_i\) — 1, якщо йому призначено медичний комплект, і 0 — інакше.

\[
\max \sum_i r_i x_i
\]

за обмежень:

\[
\sum_i x_i \leq K,\qquad x_i \in \{0,1\},
\]

де \(K\) — кількість доступних комплектів.

У коді використано сортування за балом ризику та призначення комплектів особам із найвищими балами.

## Важливе застереження

Це демонстраційна навчальна система. Вимірювання генеруються програмно, порогові значення та ваги умовні. Результати не є медичним діагнозом, не замінюють лікаря та не можуть використовуватися для ухвалення реальних рішень щодо здоров’я космонавтів. Для реального застосування потрібні клінічно валідовані алгоритми, сертифіковані датчики, перевірка безпеки та відповідна сертифікація.
